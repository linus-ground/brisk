# Brisk

macOS용 RSS 리더. 이 저장소는 배포용으로, 설치 파일(DMG)만 [Releases](https://github.com/linus-ground/brisk/releases)에 올립니다.

## 필요 환경

- Apple Silicon(M1 이후) Mac, macOS 14 Sonoma 이상
- Intel Mac에서는 실행되지 않습니다.

## 설치

1. [최신 릴리스](https://github.com/linus-ground/brisk/releases/latest)에서 `Brisk-x.y.z.dmg`를 받습니다.
2. DMG를 열고 Brisk를 '응용 프로그램(Applications)' 폴더로 드래그합니다.
3. 응용 프로그램 폴더에서 Brisk를 실행합니다.

## 업데이트

1. 메뉴 막대의 Brisk 아이콘 → '종료' (창을 닫아도 메뉴 막대에서 계속 실행 중입니다)
2. 새 DMG의 Brisk를 '응용 프로그램' 폴더로 드래그하고 '대치'
3. 다시 실행

구독 목록, 읽은 글, 설정은 업데이트해도 그대로 남습니다.
