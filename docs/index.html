Brisk

A lightweight RSS reader for macOS. It runs entirely on your Mac, with no server or account required.

Download the latest version

Requires a Mac with Apple silicon (M1 or later) and macOS 14 Sonoma or later.

Installation

  1. Download Brisk-x.y.z.dmg from the release page and open it.
  2. Drag Brisk into the Applications folder.
  3. Launch Brisk from the Applications folder.

Updates

Brisk checks for updates once a day. When a new version is available, choose Install Update and Brisk will download, verify, and install it, then relaunch. You can also check manually from the Brisk menu or the menu bar icon. Subscriptions, read status, and settings are preserved across updates.

Features

  • Folders and subscriptions with drag-and-drop organization; unread and starred lists
  • Full-text article retrieval and on-device translation
  • In-list search, single-key shortcuts (J/K/M/S/V), new-article notifications, and a desktop widget
