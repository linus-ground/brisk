Brisk

가볍고 빠른 Mac용 RSS 리더. 서버나 계정 없이 이 Mac에서만 동작해요.

최신 버전 내려받기

Apple Silicon(M1 이후) Mac · macOS 14 Sonoma 이상

설치

  1. 릴리스 페이지에서 Brisk-x.y.z.dmg를 받아 열어요.
  2. Brisk를 ‘응용 프로그램’ 폴더로 끌어다 놓아요.
  3. 응용 프로그램 폴더에서 Brisk를 실행해요.

업데이트

0.6.0부터는 앱이 하루 한 번 새 버전을 확인하고 알려 줘요. ‘업데이트 설치’를 누르면 알아서 바꾸고 다시 실행해요. 메뉴 막대 아이콘이나 Brisk 메뉴의 ‘업데이트 확인…’으로 바로 확인할 수도 있어요.

0.5.x를 쓰고 있다면 이번 한 번만 위에서 DMG를 받아 덮어써 주세요. 구독 목록, 읽은 글, 설정은 그대로 남아요.

주요 기능

  • 폴더·구독 정리 (끌어서 옮기기), 안 읽은 글·별표 목록
  • 전체 본문 가져오기, 기기 안에서 하는 한국어 번역
  • 목록 안 찾기, 한 글자 단축키(J/K/M/S/V), 새 글 알림, 위젯
